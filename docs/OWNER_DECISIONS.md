## 未审计 Actions caches 的限定提案

本轮只刷新元数据快照 [actions-cache-metadata.json](evidence/actions-cache-metadata.json)：逐项 ID、ref、大小、创建/访问时间和 key 摘要，不包含凭据值或 cache payload。普通验证 workflow 已禁用 cache；本轮不复用或执行旧缓存，也不在签名环境恢复。

选择检查时，先由维护者批准具体 ID 范围和只读获取路径；在无生产凭据、无网络发布权限的隔离环境取得原始压缩内容并加密保全，校验摘要，限定总解压量，仅读取文件/扫描，不执行脚本/JAR/二进制、不安装依赖、不启动任何缓存程序。当前 GitHub cache REST 列表只给元数据，没有取得 payload 的已验证途径；未准备自动恢复 workflow，获取路径不可用时继续标记未审计，不声称扫描通过。

选择移除时，应先批准证据保全方式、保管期及快照中明确的 ID；只调用 `DELETE /repos/ichichuang/cinema-tv/actions/caches/{cache_id}`，逐 ID 读回确认，不按模糊 key、分支或全仓库通配删除。清除缓存不能撤销已暴露的签名身份，也不证明其他副本不存在。本轮没有执行删除。
