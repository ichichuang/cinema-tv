## Global Constraints

- No product-facing UI, navigation, filters-on-screen, list layout, icons, branding or strings outside isolated candidate representations in this round. The final app requirements remain Simplified Chinese, no in-app software title or brand logo, original icon work, and D-pad-first behavior; these remain later work.
- **Strict means strict.** No fallback to a broad/unfiltered catalog when results are empty. Any explicit `Relax` operation must identify the exact condition removed, produce a changed selection and visible-to-future-UI Chinese explanation. A zero-match result never silently changes filter intent.
- Work original/declaration language is separate from playable audio language and subtitle language. 华语 is admitted by attributable Chinese work-language evidence (including multilingual work language); 非华语 needs affirmative, sufficiently scoped work-language evidence excluding Chinese. Unspecified, incomplete, known-empty or conflicting language evidence is indeterminate; it is not automatically non-Chinese. Source-declared facts remain labelled source-declared.
- Country/region is the work's **production** country/region, not a dubbed language, subtitle, service location or distribution date. Legitimate explicit co-production membership supports matching any selected country. Never split broad `欧美` into `美国`, conflate `惊悚` with `恐怖`, or derive genre/country/year from title, cover art or subtitles. Use Round 08's provenance rules and only evidence-grounded, versioned mappings.
- The movie's year selection addresses the original work release year where evidenced. Preserve source-supplied simple year as a source declaration; reject last-update date or remaster date as original release year. Unknown/conflicted year fails *exact* match; keep old years such as 1987/1994 and avoid a hardcoded 2000 floor. Year/decade/range bounds are inclusive and reject invalid/inverted bounds rather than clamping them.
- Different selected dimensions are **AND**; alternatives inside the same dimension are **OR**. An unselected dimension is neutral. For OR, any proved match -> match; if none match but some alternatives indeterminate -> indeterminate; otherwise mismatch. For AND, any proven mismatch -> mismatch; otherwise indeterminate if any unknown; else match. Final strict results contain only fully matched records.
- Never rewrite immutable source capture/evidence, stable identities, playback routes or personal data. Do not automatically link title-plus-year matches. Deduplication is by proven stable work identity only, preserving distinct playable entries and unmerged uncertain source items.
- A server accepting `year=1994` does not prove filtering support. Every candidate result is locally rechecked against evidence, even after verified pushdown. Unknown field supply, HTTP success, an empty page or a timeout must not imply complete scan or positive exact match.
- Separate `matchedInObservedData` from a *global total*: no sum of upstream totals as a de-duplicated true total. A partial query or missing per-item fact never justifies a global inventory count. Sorting of incomplete data is explicitly limited to already observed/verified rows; do not claim all-source chronological order.
- Use only synthetic named fixtures and test doubles or controlled loopback test transports. No real media source scan, public directory, discovery, scraping, TMDB/Jellyfin calls, new trust root or default source URL. `update/sources.json` remains unchanged/empty.
- Ordinary Debug and Release continue pre-round behavior, including `0.9.8` / code `18`, `armeabi-v7a`, package identity, minSdk 24/targetSdk 28, signing freeze, app startup/DI, navigation, active source manager, playback and DataStore/Room writer authority. No new production runtime activation or dual writer.
- Preserve Room schemas `1.json`–`5.json` byte-for-byte. Prefer in-memory candidate evaluation over new tables; if persistence is essential, add an explicit **v5→v6** migration, generated schema and old-data preservation tests, no destructive fallback. Never claim existing schema/DAO migration covered if not executed.
- No physical television, personal profile, real user data, push/merge/rebase, signed APK, release/tag or repository visibility change. Native Android tests only on a specifically verified, disposable AVD with `adb -s SERIAL` and confirmed ABI/API/virtual environment; report if unable to run.

## Review Focus — five critical failure classes

1. **Missing/conflicting year:** a declared 1994 work matches exact 1994; 1995, null, malformed, known-empty and conflicting 1994/1995 entries do not. The unknowns remain queryable outside exact year and carry provenance, not silently reclassified. (`StrictFilterTest`, `YearSelectorTest`)
2. **Wrong facet semantics:** JP-or-TH and action-or-crime inside dimensions, both constrained by 1980–1989, work together; one positive or conflicting language fact is handled with tri-state rules. Dubbing/subtitles do not alter work-language group. (`StrictFilterTest`)
3. **False finish:** filtered page 1 has zero accepted items, page 2 contains a 1994 match; interim result remains partial with correctly scoped continue signal, and an exhausted page has separate completeness proof. (`StrictQueryCoverageTest`)
4. **False counts/sort:** two proven-same-work source rows count as one verified matching work while preserving both entries, failures/unknown global total remain explicit, and partial chronological sorting is labelled as within the observed subset only. (`StrictProjectionTest`, Android reopen test if persisted)
5. **Stale or broadened query:** a late cancelled query or a source ignoring filter parameters cannot pollute a newer strict query; no implicit `relaxed` branch, and explicit relaxation alters only the named facet with an inspectable audit result. (`StrictQueryIntegrationTest`)
